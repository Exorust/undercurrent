| step | action | expected result (observable) |
|---|---|---|
| 1 | `grep -o 'https://[^"]*' radar/app.html \| sort -u` | exactly: `https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.5`, `https://cdn.jsdelivr.net/npm/animejs@4.5.0/dist/bundles/anime.umd.min.js`, one deck.gl 9.x URL with an exact version, one Google Fonts URL for `Inter`, `Instrument Serif` and `JetBrains Mono` (style change 2026-11-07, user: white light QM look, pm/evidence/2026-11-07-qm/); no `@latest`, no Bootstrap, no Font Awesome, no Roboto, no `motion`, no GSAP |

| 5 | `getComputedStyle(document.body).fontFamily` | starts with `Inter` (style change 2026-11-07, user: white light QM look, pm/evidence/2026-11-07-qm/); a number cell in the Topics table uses `JetBrains Mono` |
