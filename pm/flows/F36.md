## Flow F36.1 — the page loads only the agreed libraries, pinned
Preconditions: `radar/app.html` exists.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `grep -o 'https://[^"]*' radar/app.html \| sort -u` | exactly: `https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.5`, `https://cdn.jsdelivr.net/npm/animejs@4.5.0/dist/bundles/anime.umd.min.js`, one deck.gl 9.x URL with an exact version, one Google Fonts URL for `Liter` and `JetBrains Mono` (style change 2026-11-07, user: emulate fuselabcreative.com); no `@latest`, no Bootstrap, no Font Awesome, no Roboto, no `motion`, no GSAP |

| 4 | `typeof anime` in the console | `function` or `object` with `anime.animate` (v4 API) |
| 5 | `getComputedStyle(document.body).fontFamily` | starts with `Liter` (style change 2026-11-07, user: emulate fuselabcreative.com); a number cell in the Topics table uses `JetBrains Mono` |
