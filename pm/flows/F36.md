Walk with: `grep` on `radar/app.html`, headless Chrome console and network log.

Preconditions: `radar/app.html` exists.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `grep -o 'https://[^"]*' radar/app.html \| sort -u` | exactly: `https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.5`, `https://cdn.jsdelivr.net/npm/animejs@4.5.0/dist/bundles/anime.umd.min.js`, one deck.gl 9.x URL with an exact version, one Google Fonts URL for `Inter` and `JetBrains Mono` (style change 2026-11-07, user: replicate the style of pm/evidence/2026-11-07-glass/reference.png; layout and features unchanged); no `@latest`, no Bootstrap, no Font Awesome, no Roboto, no `motion`, no GSAP |

| 4 | `typeof anime` in the console | `function` or `object` with `anime.animate` (v4 API) |
| 5 | `getComputedStyle(document.body).fontFamily` | starts with `Inter` (style change 2026-11-07, user: replicate the style of pm/evidence/2026-11-07-glass/reference.png; layout and features unchanged); a number cell in the Topics table uses `JetBrains Mono` |

## Flow F36.3 — animation is used where the UI plan asks and nowhere else
Preconditions: page loaded.
| step | action | expected result (observable) |
|---|---|---|
