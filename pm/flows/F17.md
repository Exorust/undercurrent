# F17 — Map of all points

Walk with: headless Chrome via the scratchpad puppeteer script (`shot.cjs`, system Chrome) or `obscura fetch http://localhost:8765 --allow-private-network --screenshot`. WebGL is required, so prefer the puppeteer script; obscura is the fallback for DOM-only checks.

## Flow F17.1 — load and first draw
Preconditions: server running (F8.1); a fresh browser profile (no cache).
| step | action | expected result (observable) |
|---|---|---|
| 1 | open `http://localhost:8765/` | within 1 s the header, left column, Topics tab and inspector summary are visible (they do not wait for points) |
| 2 | during the points download | the map area shows `Loading map points: N of 7.8 MB` with a progress bar that moves |
| 3 | after load | the canvas shows the point cloud; `window.__radar.nPoints === 459249` (a debug handle exposed for tests); the loading block is gone |
| 4 | screenshot `evidence/<date>/F17.1/default.png` | visually the same cluster shapes as `report/map.html` (same UMAP run) |
| 5 | `performance.measure` exposed as `window.__radar.firstDrawMs` | under 2,000 ms on the laptop; recorded in STATUS |
| 6 | if `firstRecolorMs > 1000` | the line `Large map: colour changes take about N s on this machine.` appears under the legend once; otherwise it does not appear |

## Flow F17.2 — pan, zoom, fit
Preconditions: F17.1 passed.
| step | action | expected result (observable) |
|---|---|---|
| 1 | scroll-zoom on the canvas 3 steps | `window.__radar.zoom` increased; point radius grows up to 4 px (check via the layer props: `radiusMaxPixels === 4`) |
| 2 | drag the canvas | `window.__radar.viewState.target` changed |
| 3 | press `0` with the canvas focused | view returns to the full-map fit (`zoom` equals the initial value ± 0.01) |
| 4 | click the `+` and `−` buttons top-right | zoom changes by one step each |
| 5 | frame time while panning (`window.__radar.lastFrameMs`, max over 2 s of drag) | under 1,000 ms (success criterion: no stall over 1 s); recorded in STATUS |

## Flow F17.3 — performance fallback
Preconditions: a run where F17.2 step 5 or F17.1 step 6 failed on the laptop.
| step | action | expected result (observable) |
|---|---|---|
| 1 | reload | the page uses topic-level colour (one colour per cluster, no per-point attribute update) or draws a 150,000-point sample, and shows the line `Showing a 150k sample for speed; stats use all 459k papers.` |
| 2 | STATUS | records which fallback is active and the measured numbers |
