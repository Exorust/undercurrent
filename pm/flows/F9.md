# F9 — Request guards, per-request cursors, error envelope

Walk with: `curl` against a running server (F8.1).

## Flow F9.1 — Host and Origin guard
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `curl -s -H 'Host: evil.example' -w ' %{http_code}' localhost:8765/meta` | body `{"error":"forbidden","message":"...Host...","run_id":...}`; code `403` |
| 2 | `curl -s -H 'Host: 127.0.0.1:8765' -w ' %{http_code}' 127.0.0.1:8765/meta` | `200` |
| 3 | `curl -s -X POST -H 'Content-Type: application/json' -d '{"rows":[1,2,3]}' -w ' %{http_code}' localhost:8765/select` (no Origin) | `403`, `error` = `forbidden`, message mentions `Origin` |
| 4 | same with `-H 'Origin: http://localhost:8765'` | `200` with a `sel_id` |
| 5 | same with `-H 'Origin: http://attacker.test'` | `403` |
| 6 | `GET` requests without Origin | `200` (Origin is checked on POST only) |

## Flow F9.2 — body and type checks
Preconditions: server running, `O='-H Origin:http://localhost:8765'`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select` with `Content-Type: text/plain` | `415`, `error` = `bad_type` |
| 2 | `POST /select` with a 9 MB JSON body | `413`, `error` = `too_large`; server still answers `GET /meta` afterwards |
| 3 | `POST /select -d '{"rows":[1],"phrase":"x"}'` | `400`, `error` = `bad_request`, message `exactly one of rows, topic, phrase, query, sel_id` |
| 4 | `POST /select -d '{"rows":[-1]}'` and `-d '{"rows":[999999999]}'` | both `400` |
| 5 | `GET /nothing` | `404`, `error` = `not_found` |
| 6 | `GET /topics?from=2030-01&to=2030-06` | `400`, message says the window is outside the data |

## Flow F9.3 — concurrency: 20 parallel requests, no shared-cursor failure
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `seq 20 \| xargs -P 20 -I{} curl -s -o /dev/null -w '%{http_code}\n' 'localhost:8765/topics?level=1'` | twenty lines of `200`; server log (`data/log/serve.log`) has no traceback |
| 2 | 10 parallel `POST /selections` saves of different transient selections | all `200`; `select count(*) from selections` in `data/workbench.duckdb` grew by 10 |

## Flow F9.4 — internal error envelope
Preconditions: server started with `RADAR_FAULT=1` (a test hook that raises inside one handler) or a request known to fail on the dev database.
| step | action | expected result (observable) |
|---|---|---|
| 1 | trigger the failing handler | `500`, body `{"error":"internal","message":"<exception type>","run_id":...}`; traceback in `data/log/serve.log` with a timestamp; the server keeps serving `GET /meta` |
