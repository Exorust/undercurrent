# F10 — Static and meta endpoints

Walk with: `curl` against a running server.

## Flow F10.1 — the page, the points file and meta
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `curl -s -D - -o /dev/null localhost:8765/points.bin` | `200`, `Content-Type: application/octet-stream`, `Content-Length` equal to `ls -l report/points.bin`, `Cache-Control` present with the run id as `ETag` |
| 2 | `curl -s -H 'If-None-Match: "<run_id>"' -o /dev/null -w '%{http_code}' localhost:8765/points.bin` | `304` |
| 3 | `curl -s -o /dev/null -w '%{http_code}' localhost:8765/points.ids` | `404` (the id file is not served; the design dropped it) |
| 4 | `curl -s localhost:8765/meta \| python3 -m json.tool` | keys exactly: `run_id, n_points, months, last_complete, categories, levels, bridge_T, onset_share, knn_recall14, knn_bridge_agree, backtest_line, level0_links, stale_removed, started` (`started` = server start time, ISO, for the F32.4 footer; PM correction 2026-11-06); `months[0]` = `2023-11`; `months[-1]` = last complete month |
