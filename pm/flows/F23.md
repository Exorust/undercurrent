## Flow F23.1 — open evidence from an edge
Preconditions: preset 2; A already holds a topic (to test "back").
| step | action | expected result (observable) |
|---|---|---|
| 1 | click an edge | the edge draws at full opacity, 2 px wider; both end nodes get white rings |
| 2 | inspector top | `← back` link, then title `<topic 1> ↔ <topic 2>` and a status tag `new` / `forming` / `steady` / `fading` (forming when growth ≥ 1.41, fading when ≤ 0.71, steady between; tag colour = edge colour) |
| 3 | numbers block | `bridge papers in window: 412`, `in prior window: 280`, `share now 1.4%`, `share before 1.0%`, `link growth ×1.46`, `strength 0.031`; equal to `/links` and `/link` |
| 4 | definition line | one line with a `how this is measured` disclosure that opens the full bridge, strength and share text |
| 5 | bridge papers list | 10 per page, sorted by citations; each row: title (link to `https://arxiv.org/abs/<id>`), id, month, split text `6 of 14 neighbours in <topic 2>`; a `newest first` toggle re-sorts; `next` pages through up to 30 |
| 6 | shared rising phrases | each with `n1 / n2 papers` and the grey mark `all 36 months`; empty state `no shared rising phrases` |
| 7 | `Show bridge papers on map` | the bridge papers draw as 3 px white points over the dimmed map; pressing again hides them |
| 8 | `Set as A and B` | A = topic 1, B = topic 2 (outlines magenta and green); the inspector switches to the A vs B view (F28) |
| 9 | `← back` (from step 6, before step 8) | inspector returns to the previous A selection view; edge highlight clears |
| 10 | Escape in the evidence view | same as `← back` |
