# F25 — Lasso

Walk with: headless Chrome with synthetic mouse events on the canvas.

## Flow F25.1 — draw a region
Preconditions: page loaded, nothing selected.
| step | action | expected result (observable) |
|---|---|---|
| 1 | press `L` (or click the lasso button) | cursor becomes a crosshair; the lasso button shows the active style; dragging no longer pans (`window.__radar.mode === 'lasso'`) |
| 2 | press-drag a freehand path around a dense region, release | a white polygon closes; `window.__radar.lastLassoMs` under 150 ms for the point-in-polygon pass |
| 3 | request sent | `POST /select {"rows":[...]}` with the row indices inside the polygon (count equals `window.__radar.selection().current.n`) |
| 4 | label | `Lasso, 1,204 papers, mostly <topic> (62%)` with real numbers from `topics[level=1][0]` |
| 5 | slot | enters A if A was empty (F24.1), else offers `Set as B` / `Replace A` |
| 6 | the cursor | returns to the pan cursor after release; `L` again re-arms |

## Flow F25.2 — too small
Preconditions: lasso armed.
| step | action | expected result (observable) |
|---|---|---|
| 1 | draw a polygon around fewer than 20 points | inspector shows `Only 7 papers: too few for growth or phrases. Drag a larger area.`; no `POST /select` is sent (network log) |
| 2 | draw a polygon around zero points | same message with `0 papers`; nothing sent |

## Flow F25.3 — cancel
Preconditions: lasso armed, drag in progress.
| step | action | expected result (observable) |
|---|---|---|
| 1 | press Esc mid-drag | the partial path disappears; mode returns to pan; nothing sent |
