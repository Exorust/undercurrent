# F4 — Bridges, `paper_topics`, `topic_links`, calibration of T

Walk with: `.venv/bin/python -m radar.links` (the stage) and `.venv/bin/python -m radar.links --calibrate`; DuckDB queries read-only.

## Flow F4.1 — the links stage writes the bridge tables
Preconditions: F2 passed; no server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `.venv/bin/python -m radar.links` | exit code 0; stderr prints `T = <int>` (the bridge threshold used), row counts for `paper_topics`, `bridges`, `topic_links`, and `links_run_id = <map run id>` |
| 2 | `select level, count(*) from paper_topics group by level` | three levels; each paper appears with at least one row per level; `sum(nbr_share)` per `(id, level)` = 1.0 ± 1e-6 (spot check 5 ids) |
| 3 | `select level, count(*) from bridges group by level` | three rows; level 1 count between 1% and 15% of 459,249 (sanity band; the real number is recorded in STATUS) |
| 4 | `select * from bridges where level = 1 limit 5` | for each row `share1 >= T/14` and `share2 >= T/14` and `c1 < c2` |
| 5 | `select count(*), min(month), max(month) from topic_links where level = 1` | months run from `2023-11` to the last complete month; no partial current month present |
| 6 | `select sum(n_bridge) from topic_links where level = 1` equals `select count(*) from bridges where level = 1` | equal |
| 7 | `select links_run_id from map_meta order by created desc limit 1` | equals `run_id` of the same row |

## Flow F4.2 — calibration prints the evidence for T
Preconditions: F4.1 passed.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `.venv/bin/python -m radar.links --calibrate` | stdout is a table with one row per candidate T (at least 2, 3, 4, 5, 6): number of bridges, strength of the named positive pairs (robot manipulation ↔ diffusion/flow; LLM agents ↔ code generation) and of the named negative pairs (graph algorithms ↔ medical imaging; numerical PDE ↔ recommender systems) |
| 2 | read the table | at the chosen T, every positive pair ranks inside the top 40 pairs by strength at level 1 and every negative pair ranks outside the top 200; the chosen T is marked with `*` |
| 3 | `--calibrate` runs read-only | `select count(*) from bridges` unchanged after the run |
