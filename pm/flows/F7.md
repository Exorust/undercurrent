# F7 — Run lock between `run_all.sh` and the server

Walk with: shell. Use `RADAR_DRY=1 ./run_all.sh` or an equivalent fast path if the build adds one; otherwise run against the dev database.

## Flow F7.1 — the pipeline writes and removes its lock
Preconditions: no `data/run.lock`, no `data/serve.pid`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | start `./run_all.sh` in the background; within 2 s `cat data/run.lock` | the file contains the shell's pid; `ps -p <pid> -o comm=` prints `bash` or `sh` (run_all.sh) |
| 2 | let it finish (or kill it with SIGTERM) | `data/run.lock` is gone in both cases (the `trap ... EXIT` ran) |
| 3 | `kill -9` a running `run_all.sh` | `data/run.lock` remains (SIGKILL skips the trap); next start prints `removed stale lock data/run.lock (pid N not running)` and continues |

## Flow F7.2 — the pipeline refuses to start while the server is live
Preconditions: server running (F8.1).
| step | action | expected result (observable) |
|---|---|---|
| 1 | `./run_all.sh` | stderr: `data/serve.pid names a running server (pid N, radar.serve). Stop it first.`; exit code 1; no stage ran (`select max(created) from map_meta` unchanged) |

## Flow F7.3 — stale and reused pid
Preconditions: no server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `echo 1 > data/serve.pid` (pid 1 is `launchd`, alive but wrong command) then `./run_all.sh` | prints `removed stale lock data/serve.pid (pid 1 is launchd, not radar.serve)`; continues |
| 2 | `echo 999999 > data/serve.pid` then `./run_all.sh` | prints `removed stale lock ... (pid 999999 not running)`; continues |
