# F29 — Ideas UI and Ideas tab

Walk with: headless Chrome; the real model call once (F29.1), fault injection for the rest (same test hook as F16.3).

## Flow F29.1 — ask for ideas
Preconditions: A and B set (two linked topics).
| step | action | expected result (observable) |
|---|---|---|
| 1 | with only A set, hover `Ideas between A and B` | disabled; tooltip `Set A and B first` |
| 2 | with A and B set, press the button | the button area shows `Sends 28 papers to the model: 8 bridge papers, 10 from A (5 most cited, 5 newest), 10 from B. Usually 10 to 40 seconds.` with the real counts, an expandable list of the 28 titles, and a `Send` button; no request has been sent yet (network log) |
| 3 | press `Send` | `POST /ideas` sent; the area shows `Asking the model … 14 s` with a live counter and `Stop waiting (the result will still be saved)`; the rest of the page stays usable (click another topic works) |
| 4 | press the Ideas button again while waiting | nothing is sent; the area reads `one request at a time` |
| 5 | on success | ideas render in the inspector: title, text, each `arXiv:ID` as a link tagged `A`, `B` or `bridge`; header `Generated 2026-11-06 14:10 from 28 papers (window May to Oct 2026)` |
| 6 | Ideas tab | a new row with date, A name, B name, idea count; clicking it shows the ideas |
| 7 | if the user moved to another selection before the answer | a 6 s toast `3 ideas ready for <A> ↔ <B>. Open`; `Open` shows them |
| 8 | after a page reload | the Ideas tab still lists the row (from `GET /ideas`) |

## Flow F29.2 — stop waiting, slow and failing calls (fault injection)
Preconditions: server with the fake model hook.
| step | action | expected result (observable) |
|---|---|---|
| 1 | fake sleeps 20 s; press `Stop waiting` at 5 s | the counter disappears; the inspector returns to the A vs B view; when the server finishes, the Ideas tab gets the row and the toast appears |
| 2 | fake sleeps 100 s | at 90 s the counter turns grey and reads `Still waiting (90 s). The model may be slow or stuck.`; the page keeps waiting |
| 3 | fake exits non-zero | inspector: `The model call failed: claude -p exited with code 1 (<first line of stderr>). Nothing was saved.` on a `#2a1a1a` background, text `#dddddd`, plus `Try again` |
| 4 | fake cites an unknown id twice | under the passing ideas: `1 idea dropped: it cited arXiv:2405.01234, which was not among the 28 papers sent, and the retry also failed.` |
| 5 | all ideas drop | `No idea passed the citation check (3 dropped). This happens when the model cites papers it was not shown.` plus `Try again` |
| 6 | server returns `409 ideas_busy` (second tab) | `Another ideas request is running. Wait for it to finish.` |
