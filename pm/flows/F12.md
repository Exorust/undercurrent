# F12 — `GET /links` and `GET /link`

Walk with: `curl`.

## Flow F12.1 — link list for the default window
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `GET /links?level=1` | `rule` = `{k: 14, T: <bridge_T from /meta>, strength: "B/sqrt(n1*n2)", share: "B/(n1+n2)"}`; `phrase_window` = `"whole corpus"` |
| 2 | `bridge_links` order | all `status: "new"` first (sorted by `n_bridge` desc), then `status: "ratio"` by `growth` desc, then `status: "low"` by `n_bridge` desc |
| 3 | a `new` pair | `n_bridge >= 10` and prior-window bridges < 3 (`share_prior` null or a flag), `growth` null |
| 4 | a `low` pair | `n_bridge < 10`, `growth` null, `share_now` present |
| 5 | a `ratio` pair: recompute `strength = n_bridge / sqrt(n1*n2)` and `growth = share_now / ((prior_bridges + 1) / (n1p + n2p + 1))` from `topic_links` and `topic_months` | both equal ± 1e-6 |
| 6 | `c1 < c2` for every pair; no pair appears twice | true |
| 7 | `phrase_links` | each entry has `c1, c2, phrases[]` with `phrase, n1, n2, share1, share2`; every `n >= 10`, every `share >= 0.2` |

## Flow F12.2 — link evidence
Preconditions: a pair `(c1, c2)` from F12.1 with `n_bridge >= 10`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `GET /link?level=1&c1=&c2=` | `n_bridge` equals the list value; `bridges` ≤ 30 entries sorted by `citations` desc, each a `paper` plus `k1, k2` with `k1 >= T` and `k2 >= T`; every bridge paper's `month` inside the window |
| 2 | `phrases` | same entries as the pair's `phrase_links` entry (or empty) |
| 3 | `GET /link?level=1&c1=5&c2=5` | `400` |
| 4 | `GET /link` for a pair with 0 bridges | `200`, `n_bridge: 0`, `bridges: []` |

## Flow F12.3 — levels
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `GET /links?level=2` | ≤ 190 pairs (20 choose 2) |
| 2 | `GET /links?level=0` | returns within 1 s, or `level0_links: false` in `/meta` and this call returns `400` with `level 0 links not computed` (decision recorded in STATUS) |
