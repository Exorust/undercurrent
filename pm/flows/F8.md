# F8 — Server lifecycle

Walk with: shell + `curl`. `H='-H Host:localhost:8765'` is implied on every curl below.

## Flow F8.1 — start, serve, stop
Preconditions: F2–F6 ran on the current database; no `data/run.lock`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `.venv/bin/python -m radar.serve` | within 20 s stdout prints `undercurrent workbench: http://localhost:8765  (run <run_id>, 459,249 points, vectors loaded in N s)`; `cat data/serve.pid` equals the process pid |
| 2 | `curl -s -o /dev/null -w '%{http_code}' localhost:8765/` | `200`; body is HTML containing `<title>undercurrent` |
| 3 | `curl -s localhost:8765/meta` | JSON with `run_id` equal to `map_meta.run_id`, `n_points` 459249, `last_complete` = last complete month, `levels` `{"2":20,"1":116,"0":368}`, `bridge_T`, `knn_recall14`, `backtest_line` |
| 4 | `ps -o rss= -p <pid>` | between 1.5 GB and 4 GB (vectors 1.4 GB plus arrays) |
| 5 | `kill -TERM <pid>` | process exits within 5 s; `data/serve.pid` is removed |
| 6 | `lsof -iTCP:8765 -sTCP:LISTEN` after stop | no output |

## Flow F8.2 — refuses to start when the pipeline is live
Preconditions: `./run_all.sh` running (or `echo $$ > data/run.lock` from a live shell whose command name is `bash` running `run_all.sh`).
| step | action | expected result (observable) |
|---|---|---|
| 1 | `.venv/bin/python -m radar.serve` | stderr: `data/run.lock names a running pipeline (pid N, run_all.sh). Wait for it to finish, or delete the file if you are sure it is not running.`; exit code 1; port 8765 not open |

## Flow F8.3 — refuses to start when `map` ran but `links` did not
Preconditions: `update map_meta set links_run_id = NULL` on a dev copy, or run `radar.map` without `radar.links`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | start the server | stderr: `map run <id> has no links stage. Run: .venv/bin/python -m radar.links`; exit code 1 |

## Flow F8.4 — stale pid handling at start
Preconditions: `echo 999999 > data/serve.pid`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | start the server | stdout contains `removed stale lock data/serve.pid (pid 999999 not running)`; server starts; `GET /meta` includes `"stale_removed": "data/serve.pid ..."` so the page can show it (F32) |

## Flow F8.5 — port already in use
Preconditions: another process on 8765 (`python3 -m http.server 8765` in another shell).
| step | action | expected result (observable) |
|---|---|---|
| 1 | start the server | stderr: `port 8765 is in use (not by radar.serve). Stop that process or run with --port 8766.`; exit code 1 |
| 2 | `.venv/bin/python -m radar.serve --port 8766` | starts; prints the 8766 URL; Host guard accepts `localhost:8766` |
