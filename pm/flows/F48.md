## Flow F48.1 — data
| step | action | expected result (observable) |
|---|---|---|
| 1 | `select count(distinct id) from paper_institutions` / 459,249 | coverage printed by `radar.load_extra`; matches spike S2 within 5 points |

## Flow F48.2 — filter on the page
| step | action | expected result (observable) |
|---|---|---|
| 1 | sidebar shows a `Filter` row under the view rows | clicking it opens the filter panel on the right with `← Back`; text `Affiliations known for N % of papers.` |
| 2 | type `stanf` in the institution box | within 150 ms a list shows `Stanford University · US · 4,812 papers` (first match by paper count) |
| 3 | pick it | non-matching points dim; a chip `Stanford University ×` shows in the title bar; URL gains `inst=<openalex id>`; Topics sheet shows a `Matching` column, and the topic inspector shows `From this filter: 37 papers` |
| 4 | add a second institution | points from either stay bright (OR); chip count 2 |
| 5 | set country `DE` too | only points matching (inst1 OR inst2) AND DE stay bright; if none, the map shows `No papers match these filters.` and a `Clear filters` button |
| 6 | press × on a chip | that filter goes; the map updates |
| 7 | reload the page with the URL | the same filters are active |
| 8 | a sixth institution | the box refuses with `Up to 5 institutions.` |
| 9 | topic inspector without filters | `Top institutions: …` lists 5 with paper counts |
| 10 | keyboard only | the panel is reachable by Tab, the type-ahead works with ↑ ↓ Enter, chips remove with Enter or Backspace; axe reports 0 violations |
