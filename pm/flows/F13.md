# F13 — `POST /select`: rows, topic, phrase, query; stats and distinctive terms

Walk with: `curl` with `-H 'Origin: http://localhost:8765' -H 'Content-Type: application/json'`.

## Flow F13.1 — select a topic
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select -d '{"topic":{"level":1,"c":63}}'` | `200`; `sel_id` string; `kind: "topic"`; `n` equals `select n from topics where level=1 and cluster=63`; `n_unembedded: 0`; no `rows` key |
| 2 | `months` | array of 36 integers (one per month since 2023-11 up to the last complete month); sum ≤ `n` |
| 3 | `growth` | `{recent, prior, growth, is_new, window}`; `growth` equals the same topic's value from `GET /topics` |
| 4 | `top_cited` and `newest` | 10 each; `top_cited` sorted by `citations` desc; `newest` sorted by `month` desc; every `id` is a member of cluster 63 |
| 5 | `terms` | up to 20 entries `{term, k, share_sel, share_all, delta, z}`; every `k >= 3`; every `z >= 3`; sorted by `delta` desc; the top 5 terms read as the topic's subject (pasted into STATUS) |
| 6 | `topics` | for level 1 the top entry is cluster 63 with `own_share` ≈ 1.0; other entries have `nbr_share` from `paper_topics` |

## Flow F13.2 — select rows (lasso payload)
Preconditions: server running; take 1,500 rows of one fine cluster from `points.bin` plus 200 random rows.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select -d '{"rows":[...]}'` | `200`; `kind: "rows"`; `n` = number of distinct rows sent (duplicates removed) |
| 2 | `topics[level=0][0].own_share` | about `1500 / 1700` ± 0.02 |
| 3 | send 15 rows | `200`, `growth.growth` null with `recent` and `prior` numbers; `terms` is `[]` (fewer than 3 papers per term) |
| 4 | send 25,000 rows | `200` within 3 s; response has `terms_sampled: 20000` |

## Flow F13.3 — phrase and title search
Preconditions: server running.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select -d '{"phrase":"world action models"}'` | `kind: "phrase"`; `n + n_unembedded` equals `select count(*) from papers where contains(lower(title \|\| ' ' \|\| abstract), 'world action models')`; `rows` present and sorted |
| 2 | `POST /select -d '{"phrase":"zzqx not a phrase"}'` | `422`, `error: "empty_selection"`, message includes up to 3 nearest rising phrases by edit distance (may be empty) |
| 3 | `POST /select -d '{"query":"diffusion"}'` | `kind: "query"`; `n` equals `select count(*) from papers p join point_index using(id) where p.title ilike '%diffusion%'` |
| 4 | `POST /select -d '{"query":"100%_safe\\\\"}'` | `200` or `422`, never `500`; the server log shows a parameterised query (no raw user text in SQL) |
| 5 | `POST /select -d '{"query":"'\''; drop table papers; --"}'` | `422` (no match); `select count(*) from papers` unchanged |
| 6 | time step 1 | under 2.5 s (full-text scan budget); time step 3 under 1 s |

## Flow F13.4 — transient selection lifetime
Preconditions: a `sel_id` from F13.1.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select -d '{"sel_id":"<id>"}'` | `200`, same `n` |
| 2 | restart the server; repeat | `404`, `error: "not_found"` (transient selections are memory only) |
| 3 | `POST /select -d '{"sel_id":"nope"}'` | `404` |
