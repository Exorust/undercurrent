# F26 — Search: phrase and title

Walk with: headless Chrome, typing into the search box.

## Flow F26.1 — phrase search with suggestions
Preconditions: page loaded.
| step | action | expected result (observable) |
|---|---|---|
| 1 | press `/` | the search box has focus; the toggle under it shows `phrase` selected and `title` unselected |
| 2 | type `world action` | a dropdown lists matching rising phrases with counts and growth, for example `world action models · 200 papers · ×13.0` and `world-action models · 137 papers · ×22.0` (hyphen variant visible) |
| 3 | press Enter on `world action models` | `POST /select {"phrase":"world action models"}` sent; matching points draw at 2 px with a white ring; other points dim; the map does not zoom |
| 4 | inspector label | `phrase: "world action models"` and the note `literal match on title and abstract; 3 of 200 papers are not on the map (not embedded)` with real numbers (`n_unembedded`) |
| 5 | press `Zoom to matches` | the view fits the bounding box of the matched points |
| 6 | slot | enters A if empty, else `Set as B` / `Replace A` |

## Flow F26.2 — title search
Preconditions: page loaded.
| step | action | expected result (observable) |
|---|---|---|
| 1 | switch the toggle to `title`, type `diffusion`, Enter | `POST /select {"query":"diffusion"}`; inspector label `title contains "diffusion"`; `n` equals the F13.3 step 3 count |
| 2 | type `%` alone, Enter | no `500`; the inspector shows either matches or the zero-match message |

## Flow F26.3 — zero matches
Preconditions: phrase mode.
| step | action | expected result (observable) |
|---|---|---|
| 1 | type `wolrd action models`, Enter | inspector: `No paper title or abstract contains "wolrd action models". Phrase search is a literal match: check spelling or try a variant.` followed by up to 3 nearest rising phrases as clickable chips (`world action models` among them) |
| 2 | click a suggested chip | runs that phrase search (F26.1 step 3 onwards) |
