# F50 — Performance budget

Walk with: `node tools/perf.cjs <url>` (headless Chrome, cache disabled, no CPU throttling, 1600 × 1000), run against the local static build and the live site. Baseline before this round (2026-11-07): first draw 1.11 s, slowest frame 17 ms.

## Flow F50.1 — load
| step | action | expected result (observable) |
|---|---|---|
| 1 | load the map | `firstDrawMs` ≤ 1500 |
| 2 | list requests before first draw | same files as the baseline list in `data/spikes/perf-baseline.json`, plus at most 20 KB more in total; no filter file, no institution file |
| 3 | response headers of `.json` and `.bin` data files on the live site | `content-encoding: br` or `gzip`; if `.bin` is not compressed the report names the file and its size |

## Flow F50.2 — filtering
| step | action | expected result (observable) |
|---|---|---|
| 1 | open Filter the first time | the per-point arrays load; transferred total ≤ 600 KB |
| 2 | the institution list loads | ≤ 150 KB transferred |
| 3 | pick an institution | its row file ≤ 64 KB transferred; `filterApplyMs` (mask build + recolour) ≤ 100 |
| 4 | change filters 10 times in a row | each `filterApplyMs` ≤ 100; `maxFrameMs` ≤ 33 |
| 5 | pan for 3 s with a filter on | `maxFrameMs` ≤ 17 |
| 6 | `find site -type f | wc -l` | ≤ 10,000 |
| 7 | `python -m radar.export --selftest` | prints `ok`; it fails if any budget in steps 2–6 is broken |
