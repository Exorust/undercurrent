# F30 — Saved selections UI

Walk with: headless Chrome; the dev database for the rerun case.

## Flow F30.1 — save
Preconditions: a lasso selection in the inspector.
| step | action | expected result (observable) |
|---|---|---|
| 1 | press `Save` (or Cmd+S) | an inline text field opens under the title with the current label as the default; the browser's own save dialog does not open |
| 2 | type `gap robots-diffusion`, Enter | `POST /selections` sent with the transient `sel_id` (the server already holds the ids), polygon, window and run id (PM correction 2026-11-07); the saved list (left column) shows the new item at the top: `gap robots-diffusion · 1,204 papers · 2026-11-06` |
| 3 | Enter on an empty name | field shows `name required`; nothing sent |
| 4 | Escape in the field | field closes; nothing saved |
| 5 | save the home field: search phrase `metal kernel`, `Set as A`, Save as `home field` | appears in the list; this replaces `merge.py`'s fixed `DEFAULT_HOME` as the way to define the home field |

## Flow F30.2 — reopen
Preconditions: saved items exist; same map run.
| step | action | expected result (observable) |
|---|---|---|
| 1 | click a saved item | it loads as the current selection with its polygon drawn; the inspector title `Saved: gap robots-diffusion (now mostly <topic>, 62%)`; no restore note |
| 2 | choose it in the A dropdown | loads into A directly |
| 3 | `×` next to a saved item | confirm text `Delete "gap robots-diffusion"? Ideas that reference it block deletion.`; confirm → gone from the list; if referenced, the message `Cannot delete: 2 ideas reference this selection.` |

## Flow F30.3 — reopen after a pipeline rerun
Preconditions: a saved lasso from run R1; pipeline rerun (dev database) → run R2; server restarted.
| step | action | expected result (observable) |
|---|---|---|
| 1 | click the saved item | papers highlighted on the new layout; no polygon drawn; note `Restored 1,204 papers. The map layout changed since you saved this on 2026-11-06, so the old lasso outline is not shown; the papers are highlighted instead.` |
| 2 | if ids are missing | note `Restored 1,198 of 1,204 papers; 6 are no longer on the map.` |
| 3 | stats | computed for the current window; grey line `saved with window May to Oct 2026` under the title |
| 4 | Ideas tab | ideas made in R1 still listed with their A and B names |
