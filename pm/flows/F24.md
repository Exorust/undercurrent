# F24 — Select by click; slot rules; Escape

Walk with: headless Chrome; `window.__radar.selection()` returns `{current, A, B}` with `sel_id` and `n`.

## Flow F24.1 — first click fills A
Preconditions: fresh page, nothing selected.
| step | action | expected result (observable) |
|---|---|---|
| 1 | click a point inside a topic | a white hull appears for ≤ 300 ms, then turns magenta with a 15% fill and an `A` tag; the A slot chip in the left column shows the topic label and paper count |
| 2 | `POST /select` sent | one request with `{"topic":{"level":1,"c":<id>}}` (the page sends the cluster, not 2,000 rows, when a whole cluster is selected) |
| 3 | inspector | fills in order: `Topic, in area <area>`, `papers in window N (prior M)`, `×g after correction (raw ×r; all CS grew ×1.36)`, 36 monthly bars with the window shaded, arriving sub-topics, distinctive phrases, top cited (10), newest (10), links to other topics |
| 4 | points outside A | opacity drops to 0.08; inside keep their colour at 0.6 |

## Flow F24.2 — second click does not overwrite A
Preconditions: A set.
| step | action | expected result (observable) |
|---|---|---|
| 1 | click another topic | a white hull outlines it; A's magenta hull stays; the inspector shows the new topic with buttons `Set as B` and `Replace A` |
| 2 | press `Set as B` (or key `B`) | the hull turns green with a `B` tag; the A vs B block appears (F28) |
| 3 | click a third topic, press `Replace A` | A becomes the third topic; B unchanged |
| 4 | click a node (preset 2), a badge, or a Topics row | same behaviour as a point click |
| 5 | click empty map space | nothing changes |

## Flow F24.3 — Escape order
Preconditions: A and B set, an unassigned current selection, the (i) popover open.
| step | action | expected result (observable) |
|---|---|---|
| 1 | Esc | popover closes |
| 2 | Esc | current unassigned selection cleared (white hull gone) |
| 3 | Esc | B cleared |
| 4 | Esc | A cleared; inspector returns to the window summary (F27.2); all points back to the page-load opacity (0.35 base alpha) (PM correction 2026-11-07) |
| 5 | Esc with the search box focused | keys are inactive in text fields: the box loses focus or clears, nothing on the map changes |

## Flow F24.4 — hover
Preconditions: zoom under 4×, then over 4×.
| step | action | expected result (observable) |
|---|---|---|
| 1 | hover a point at full-map zoom | no tooltip (picking off for cost) |
| 2 | zoom to 5×, hover a point | tooltip within 200 ms: title (from `GET /paper?row=`), month, topic, sub-topic; one `/paper` request per hovered row, cached on repeat |
