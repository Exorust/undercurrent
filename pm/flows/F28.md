# F28 — A and B slots, A vs B block

Walk with: headless Chrome.

## Flow F28.1 — set both slots and compare
Preconditions: A set from a click (F24.1).
| step | action | expected result (observable) |
|---|---|---|
| 1 | click a second topic, press key `B` | B outline green with tag `B`; the B chip shows its label and count |
| 2 | inspector top | an `A vs B` block: `cosine distance 0.071`, `overlap 0 papers`, `bridge papers between them: 412` and the first 5 bridge titles; values equal `GET /distance` |
| 3 | both hulls stay on the map | A magenta, B green; points outside both at 0.08 opacity |
| 4 | press the `⇄` button between the chips | A and B swap labels and colours; the distance stays the same |
| 5 | open the A chip dropdown | lists saved selections; choosing one loads it into A (F30.2) |
| 6 | A chip `×` | clears A; the A vs B block disappears; the Ideas button becomes disabled |
