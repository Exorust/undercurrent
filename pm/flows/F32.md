# F32 — Error and status banners

Walk with: headless Chrome; stop and start the server during the walk.

## Flow F32.1 — server stops after the page loaded
Preconditions: page loaded with points drawn.
| step | action | expected result (observable) |
|---|---|---|
| 1 | kill the server | within 5 s a 32 px banner under the header: `Server not reachable at localhost:8765. Start it with .venv/bin/python -m radar.serve. The map still pans and colours; selections, tables and ideas need the server.` |
| 2 | pan and change colour mode | both still work (data already in the page) |
| 3 | click a topic | the hull draws; the inspector shows `waiting for the server` instead of stats; no error dialog |
| 4 | restart the server | the banner disappears within 5 s (retry loop); the pending selection is re-sent and the inspector fills |

## Flow F32.2 — page opened as a file
Preconditions: `open radar/app.html` directly (file:// URL).
| step | action | expected result (observable) |
|---|---|---|
| 1 | load | banner `Open http://localhost:8765 instead of the file.`; the map area shows nothing or a placeholder; no uncaught JavaScript errors in the console |

## Flow F32.3 — guard refusal
Preconditions: page opened at `http://127.0.0.1:8765` while the server's own address is `localhost:8765` (Origin mismatch on POST), or a proxy rewriting Host.
| step | action | expected result (observable) |
|---|---|---|
| 1 | click a topic | banner `The server refused this request (wrong address). Open the page at http://localhost:8765, not 127.0.0.1 through another tab or a proxy.` |

## Flow F32.4 — stale lock note
Preconditions: server started after `echo 999999 > data/serve.pid` (F8.4).
| step | action | expected result (observable) |
|---|---|---|
| 1 | load the page | footer of the left column, grey 11 px: `Server started 14:02. Removed stale lock data/serve.pid (process 999999 was not running).` |
| 2 | reload after a clean restart | the note is gone |
