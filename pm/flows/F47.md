# F47 — arXiv comments as signals

Walk with: `duckdb` queries on a copy of `data/radar.duckdb`; `python -m radar.venues --selftest`; headless Chrome on the static site (`tools/shot.cjs`) and the local server.

## Flow F47.1 — data
| step | action | expected result (observable) |
|---|---|---|
| 1 | `select count(*), count(comment) from papers` | `count(comment)` equals the share the spike measured (S1) within 2 points; no paper lost (row count unchanged) |
| 2 | `python -m radar.venues --selftest` | prints `ok`; covers at least 40 real comment strings including: `Accepted at NeurIPS 2025` → venue NeurIPS, kind accepted, year 2025; `Under review at ICLR 2026` → kind submitted; `Workshop on ... at ICML 2025` → kind workshop; `12 pages, 4 figures. Code: https://github.com/x/y` → pages 12, code_url set; `This paper has been withdrawn` → withdrawn |
| 3 | `select kind, count(*) from paper_comments group by 1` | four kinds plus null; no other values |
| 4 | a paper with no venue in its comment but a Semantic Scholar `publicationVenue` | `venue` is the S2 venue and `venue_source = 's2'` |
| 5 | weekly job harvests 14 days | the new papers have `comment` filled where arXiv has one (check 3 ids against arxiv.org/abs pages) |

## Flow F47.2 — page
| step | action | expected result (observable) |
|---|---|---|
| 1 | open any topic, read the paper list | each paper with a venue shows a pill (`NeurIPS 2025`; `NeurIPS 2025 · workshop`; `ICLR 2026 · submitted`); each paper with code shows a `code` link opening the URL in a new tab |
| 2 | topic inspector | a line `At a venue 23 % · With code 41 %` and `Top venues: NeurIPS 61, ICML 44, ICLR 38` (numbers from the data) |
| 3 | open the Topics sheet | columns `At a venue %` and `With code %`, both sortable |
| 4 | Filter → `At a venue` chip | only papers with kind accepted or workshop stay bright; the chip shows in the title bar; URL gains `venue=1` |
| 5 | Filter → `Has code` chip | same, for code links; URL gains `code=1` |
| 6 | static and local mode | both show the same pills and percentages for the same topic |
