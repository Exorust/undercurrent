# F14 — Saved selections in `data/workbench.duckdb`

Walk with: `curl` (POST headers as in F13) and DuckDB on `data/workbench.duckdb`.

## Flow F14.1 — save, list, load
Preconditions: server running; a transient `sel_id` from a lasso (F13.2) with a polygon, and one from a topic (F13.1).
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /selections -d '{"sel_id":"<lasso>","name":"gap robots-diffusion","polygon":[[x,y],...]}'` | `200`, `{sel_id}` |
| 2 | `GET /selections` | one entry with `name`, `kind: "rows"`, `n`, `created` (ISO timestamp), `run_id` = current map run id |
| 3 | `select count(*) from selections; select count(*) from selection_ids where sel_id = '<id>'` on `data/workbench.duckdb` | `1`; equals `n`; ids are arXiv ids (strings), not rows or cluster ids |
| 4 | `POST /select -d '{"sel_id":"<id>"}'` after a server restart | `200`; `n` unchanged; `missing: 0`; `polygon` returned; `saved_window` and `run_id` returned |
| 5 | `data/workbench.duckdb` is never opened by the pipeline | `grep -rln 'workbench.duckdb' radar/*.py run_all.sh` lists only `radar/serve.py` (PM correction 2026-11-06: the word alone also matches docstrings) |

## Flow F14.2 — load after a map rerun
Preconditions: a saved selection from run R1; the map and links stages rerun on the dev database (run R2); server restarted.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /select -d '{"sel_id":"<id>"}'` | `200`; `n` within ±1% of the saved `n`; `missing` ≥ 0 and equals saved ids absent from `point_index`; `polygon_valid: false` (run ids differ); `run_id` in the response is R1 |
| 2 | `topics[level=1][0]` | the current majority topic (label may differ from save time) |

## Flow F14.3 — delete, and refuse when ideas reference it
Preconditions: one saved selection with no ideas, one referenced by an idea (after F16).
| step | action | expected result (observable) |
|---|---|---|
| 1 | `POST /selections/delete -d '{"sel_id":"<free>"}'` | `200`, `{deleted: true}`; gone from `GET /selections` and from `selection_ids` |
| 2 | `POST /selections/delete -d '{"sel_id":"<referenced>"}'` | `409`, `error: "in_use"`, message names the idea count |
| 3 | `POST /selections/delete -d '{"sel_id":"nope"}'` | `404` |
| 4 | `POST /selections -d '{"sel_id":"<transient>","name":""}'` | `400` (name required) |
