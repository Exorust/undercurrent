# F35 — Verification harness

Walk with: shell.

## Flow F35.1 — one self-check per module
Preconditions: dev database per arch §8.2 (`data/dev.duckdb`, a 20k-paper sample) exists or is built by `make dev`.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `.venv/bin/python -m radar.links --selftest` | prints `ok` lines for: bridge rule on a hand-made 3-cluster graph, link growth with pseudo-counts (zero prior gives a finite ratio), onset month on a synthetic series, effective-cluster count, distinctive-term score on a toy corpus; exit code 0 |
| 2 | `.venv/bin/python -m radar.serve --selftest` | starts on a free port against the dev database, runs the Host/Origin guard, `/select` validation (400s), `/ideas` citation check with a fake model, pid-lock stale detection; prints `ok`; exits 0 within 60 s |
| 3 | `.venv/bin/python -m radar.map --selftest` | `points.bin` round trip and `knn` self-drop on a 2,000-point sample; exits 0 |
| 4 | break one rule on purpose (edit a threshold in a scratch copy) | the matching self-check fails with a non-zero exit |
