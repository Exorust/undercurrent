# F33 — Keyboard and accessibility

Walk with: headless Chrome (`page.keyboard`, `page.accessibility.snapshot()`), Chrome DevTools vision-deficiency emulation for the screenshot check.

## Flow F33.1 — keys
Preconditions: page loaded, canvas focused.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `/` | search box focused |
| 2 | type `abc`, then press `L` | the letter `L` goes into the box; lasso does not arm (keys inactive in text fields) |
| 3 | Esc, then `L` | lasso armed |
| 4 | Esc, click a topic, press `A` | current selection becomes A; click another, press `B` → B |
| 5 | `1`, `2` | question presets switch (F20) |
| 6 | `[`, `]` | window steps 3 / 6 / 12 |
| 7 | `+`, `-`, arrows, `0` with the canvas focused | zoom in, zoom out, pan, fit |
| 8 | Tab from the page start | focus order: question switch → window → (i) → level → colour → layers → search → A → B → lasso → saved → canvas → tab bar → table rows → inspector; the canvas shows a 2 px white focus ring |
| 9 | in the Topics table: ↓ ↓ Enter | third row selected |

## Flow F33.2 — screen-reader labels and text sizes
Preconditions: page loaded.
| step | action | expected result (observable) |
|---|---|---|
| 1 | accessibility snapshot of the canvas | role `img` or `application` with `aria-label` `Map of 459,249 papers, coloured by growth, May to Oct 2026`; it updates when the colour mode or window changes |
| 2 | every number on the map (badge growth, edge counts) | also present in the Topics or Links table (spot-check 3) |
| 3 | computed font sizes | body text in inspector and tables 13 px; legend and table secondary 12 px; nothing below 11 px (`getComputedStyle` over all text nodes) |
| 4 | contrast | primary `#dddddd` on `#111` ≈ 13:1; secondary `#9a9a9a` ≈ 6.5:1; no text colour darker than `#8a8a8a` on `#111` |

## Flow F33.3 — colour-blind and motion
Preconditions: default view screenshot.
| step | action | expected result (observable) |
|---|---|---|
| 1 | emulate deuteranopia and protanopia | steps 1, 4 and 7 of the growth scale remain distinguishable (different lightness and blue-yellow axis); evidence screenshots saved |
| 2 | emulate tritanopia | if blue and grey merge, `Lightness only` (F18.2 step 5) restores 7 distinguishable steps |
| 3 | set `prefers-reduced-motion: reduce` and click a sub-topic chip | the zoom is instant (no 300 ms animation); anime.js animations are skipped or set to duration 0 |
