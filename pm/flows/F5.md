## Flow F5.1 — monthly counts and onset months
Preconditions: F4.1 passed.
| step | action | expected result (observable) |
|---|---|---|
| 1 | `select level, count(distinct cluster) from topic_months group by level order by level` | `0 → 368`, `1 → 116`, `2 → 20` |
| 2 | `select sum(n) from topic_months where level = 1` | equals the number of embedded papers assigned to a level-1 cluster (not noise), same as `select count(*) from topic_members where level = 1 and cluster >= 0` |
| 3 | `select cluster, onset_month from topic_onset where level = 0 order by onset_month desc limit 10` | 10 rows; every `onset_month` ≤ last complete month (the "onset in 2026" clause dropped: latest onset is 2025-05 on this data; onset is informational only (PM correction 2026-11-07, user decision: arriving = window-share rule)) |
| 4 | for one fine cluster, recompute the month where the cumulative count first reaches 10% of its total from `topic_months` | equals its `onset_month` |
| 5 | window-share rule check: for the last 6 complete months, count level-0 clusters with ≥ 30 papers in the window and window share ≥ 1.6 × corpus share (from `topic_months`) | between 5 and 40 clusters; includes cluster `action, manipulation, robot, world` and an LLM-agent cluster; the number is recorded in STATUS (PM correction 2026-11-07, user decision: arriving = window-share rule) |
